### Featured work

**[ThinkDesk](https://github.com/saad92005/thinkdesk)**: a multi-tenant AI knowledge workspace · [live](https://thinkdesk-three.vercel.app)
Hybrid RAG (vector + BM25 fused with Reciprocal Rank Fusion, then cross-encoder reranking), research mode that marks a finding verified only when separate documents corroborate it, and AI agents that draft Slack posts but never send without human approval. Includes OAuth connectors, Lemon Squeezy billing and 105 pytest tests, with tenant isolation among them.
`Python` `FastAPI` `PostgreSQL` `Next.js` `TypeScript` `Groq`

**[Omnira](https://github.com/saad92005/omnira)**: a permission-gated AI desktop agent · [web build](https://omnira.netlify.app)
A voice and chat assistant that can open apps, create files and set timers, but only through capabilities the user grants. It has a vendor-agnostic LLM provider layer, tool calling split between server actions and client actions, OAuth with PKCE, encrypted token storage, 8 ADRs, 128 unit tests, and a real Windows installer.
`TypeScript` `Tauri` `React` `Fastify` `Prisma` `PostgreSQL`

**[AES App](https://github.com/saad92005/aes-app)**: a field operations and business management platform
Built for a real engineering services company. It covers work orders imported automatically from Gmail, GPS-verified attendance, a payroll engine with an approval workflow, double-entry accounting, inventory and 12-role access control, all in one Flutter codebase.
`Flutter` `Dart` `Firebase` `Gmail API`

**[Arabic Dialect MT](https://github.com/saad92005/arabic-dialect-mt-nlp)**: transfer learning for low-resource dialect translation
Compares a from-scratch GRU Seq2Seq model with a fine-tuned AraBERT encoder for Moroccan, Levantine, Gulf and Tunisian Arabic → English, written up as an IEEE-format paper.
`Python` `PyTorch` `Hugging Face Transformers`
